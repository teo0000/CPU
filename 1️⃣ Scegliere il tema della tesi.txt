1️⃣ Scegliere il tema della tesi

Devi definire l’obiettivo del progetto.

Esempi molto usati nelle università:

Progetto A (il più comune)
➡ progettare una CPU basata su RISC-V

Progetto B
➡ progettare una CPU personalizzata con ISA tua

Progetto C
➡ progettare un SoC (System on Chip) con CPU + periferiche

Progetto D
➡ progettare una CPU e un compilatore/assembler.

💡 Per una tesi completa hardware + software, il migliore è:

CPU + toolchain software

2️⃣ Definire l’architettura

Progetti la CPU su carta.

Decidi:

numero di bit (8 / 16 / 32)

numero registri

istruzioni

memoria

pipeline (opzionale)

Esempio semplice:

CPU 16-bit

8 registri

20 istruzioni

memoria 64 KB

3️⃣ Implementare l’hardware (HDL)

Scrivi il processore in linguaggio hardware.

Linguaggi usati:

Verilog

VHDL

Componenti da progettare:

ALU

Register file

Program Counter

Instruction decoder

Control unit

Memory interface

4️⃣ Simulazione hardware

Testi la CPU con simulatori.

Strumenti comuni:

Verilator

ModelSim

EDA Playground

Qui controlli:

se le istruzioni funzionano

se i segnali sono corretti

se il clock funziona.

5️⃣ Scrivere il software della CPU

Ora sviluppi il software che gira sopra la CPU.

Possibili lavori:

assembler

scrivere un assembler per la tua ISA

emulator

emulatore software della CPU

compilatore

supporto C usando tool come:

LLVM

GCC

6️⃣ Programmi dimostrativi

Devi dimostrare che la CPU funziona.

Esempi:

programma che fa calcoli

piccolo kernel

interprete semplice

mini sistema operativo.

7️⃣ Analisi e risultati

Parte fondamentale della tesi:

analizzare:

performance

numero di istruzioni

consumo logico

tempo di esecuzione.

8️⃣ Struttura tipica della tesi

introduzione

architettura CPU

progettazione hardware

simulazione

toolchain software

risultati

conclusioni
